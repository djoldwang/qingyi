# 轻译使用手册

本手册对应 1.0.4 发布候选。当前正式安装包与各版本发布记录见 [GitHub Releases](https://github.com/djoldwang/qingyi/releases)。

## 安装与权限

在搭载 Apple Silicon 的 Mac 上使用，系统要求 macOS 14 或更高版本。打开 DMG 后，将轻译拖入「应用程序」；使用 ZIP 时先解压再移入。打开后，从菜单栏的「译」进入设置。更新前先退出正在运行的轻译，再覆盖原安装位置，便于沿用已有授权。发行包使用固定 Qingyi 证书签名，未经 Apple 公证。

侧栏底部的「系统权限」可直接打开对应的 macOS 设置。辅助功能用于在其他应用读取选区和悬停段落；屏幕录制用于截图翻译。在设置内试用划词示例可以先跳过这两项。

## 第一次使用划词

打开 **设置 → 划词**。在试用区选择英文或中文示例，切换划词方式，就能看到当前配置会显示哪些动作。试用使用本地示例，无需配置模型或授予辅助功能权限。在其他应用中划词前，请先授予辅助功能权限。

| 选中文字后 | 怎样操作 |
| --- | --- |
| 简洁按钮（默认） | 默认外语显示“译”，中文显示“润”。移入或点击按钮即可执行。要使用自定义动作，按设置中的辅助键。 |
| 直接显示动作栏 | 点击“翻译”“润色”或某个自定义动作。动作栏只列出适用于选区且已启用的动作，移过只高亮。原应用仍可复制文字，也可用 Shift 扩展选区后再点击。 |

选用“简洁按钮”时，设置页有两项位置可调。“简洁按钮位置”控制“译”“润”按钮，默认在鼠标左下方。“动作栏位置”控制辅助键打开的自定义动作栏，默认在鼠标正下方。

选用“直接显示动作栏”时，只显示“动作栏位置”。两种方式共用这一项，改一次就会同时生效。升级时，若原先手动选过位置，简洁模式会将它保留为“简洁按钮位置”，直接显示动作栏模式会将它保留为“动作栏位置”。

可选位置包括鼠标的四个斜向位置、鼠标上方和鼠标下方。靠近屏幕边缘时，入口会调整到可见区域。

## 中文划词润色（1.0.4）

中文润色默认开启。选中中文后，在简洁按钮模式移入或点击“润”，或在直接显示的动作栏中点击“润色”。结果窗口会展示一张“AI 润色”卡片。简体、繁体、中文为主的混排文字和单个汉字均可润色。

默认提示词要求模型保留原文意思和语气，只输出修订后的正文，并遵循三项排版约定。

1. 汉字与相邻的英文、数字之间加一个半角空格，例如「2022 年 LPL 赛程」。
2. 英文按规范拼写和大小写，例如 iPhone、MacBook、Wi-Fi、email。
3. 自然语言的双引号用「」、单引号用『』，不使用英文直引号。

保留原意、语气、简繁体和段落结构，不补充事实；代码、网址、邮箱地址和技术标识符的内部字符不改动。这些要求属于内置润色默认提示词；已保存的自定义提示词继续保留，点击“恢复默认提示词”即可应用新规则。

润色使用设置中的当前 ChatGPT 或自定义 API 模型，独立于“启用 AI 翻译”开关。未配置模型时，浮窗提示配置并保留临时模型选择入口。有道和谷歌不参与润色。模型配置、服务额度与翻译共用。

可流式阅读、选择文字、复制结果、钉住或拖动窗口；字号与位置沿用现有设置。重试、临时切换模型及恢复默认模型会重新润色完整原文；关闭或开始新选区后，本次模型选择清除。每次最多 12,000 字，超长会提示缩小选区，不截断发送。

本版仅中文划词支持润色。复制中文后使用翻译快捷键仍提示已是中文，中文悬停和中文截图继续静默跳过。关闭划词或排除当前应用后，“译”和“润”入口均不出现。

## 创建和调用自定义 AI 动作

1. 打开“设置 → AI 动作”，点击列表底部的“新建 AI 动作”。填写名称和提示词，选择模型后点击“创建”。名称不能留空或重名，提示词不能为空。也可点击“总结”“解释”“会议纪要”或“智能提取”填入示例，再按需编辑提示词。切换示例会更新提示词及示例名称，保留你自行填写的其他名称；点击“创建”后才会保存为动作。动作名称会显示在浮窗按钮上，建议不超过 4 个字；这是一项建议，不强制截断长名称。
2. 提示词描述你希望 AI 做的事，执行动作时，模型会同时收到提示词和单独传入的选中文字，无需插入占位符。模型默认跟随全局，也可独立选择已配置的模型。
3. 简洁按钮模式下，选中文字，单独按一下 ⌥ Option 打开动作栏，再按一下收起。可改为按住辅助键显示、松开关闭。点击动作或用方向键和回车执行。直接显示动作栏模式下，选区确定后即可点击动作。Esc、点击外部、滚动外部内容或切换应用可收起动作栏。
4. 在“AI 动作 → 自定义动作栏设置”中可调整简洁模式的辅助键与触发方式。两种方式共用“动作栏显示上限”，可选 1～9 个，默认 4 个。直接显示动作栏时，先筛出已启用且适合本次选区的动作，再按设置顺序显示前 N 个。外语选区的“翻译”和中文选区的“润色”显示时各占一个名额。例如，上限为 2，外语选区的可用动作依次为“总结、解释、翻译”，动作栏会显示“总结、解释”。简洁模式按辅助键打开的动作栏最多显示 N 个已启用的自定义动作。
5. 点击已有动作打开编辑弹窗，有效编辑自动保存，点击“完成”返回列表。每行右侧可启用或停用该动作。拖动任意标题可调整内置动作与自定义动作的相对位置，例如把“总结”放在“翻译”前面。在目标行上松手保存预览顺序，按 Esc 取消。可在编辑弹窗内删除自定义动作。停用的动作不出现在动作栏，创建和管理动作请前往“设置 → AI 动作”。内置翻译和润色保留原有设置与恢复默认能力。

两种划词方式共用选区过滤。即使已经创建自定义动作，只选中一个网址、裸域名（如 `example.com`）、其他 URI（如 `mailto:user@example.com`）、单个外文字母、空白或纯符号和表情时，也会跳过该选区。单个汉字、数字、含文字的代码和含网址的正常句子都可以使用动作栏。选区上限为 12,000 字。

关闭内置翻译、润色或 AI 翻译结果来源后，仍可在合格选区上单独使用已启用的自定义动作。动作只将选中文字及提示词发送给所选 AI，正文中的链接仅作为文字处理。“启用划词”和排除应用设置同样适用。

执行后沿用原浮窗，以动作名称标识结果。支持流式输出、复制、钉住、拖动、重试和临时换模型。当前任务保留完整原文、名称、提示词及初始模型快照，编辑只影响下次任务；停用或删除后已有结果可保留和复制，但不能重试或换模型再执行。模型已删除或不可用时提示重新选择，不自动切换到其他服务。动作配置仅保存在本机，实际执行时会把提示词及选区发送给所选 AI。

### 在结果窗口切换动作

润色或执行自定义动作后，点击结果下方的动作即可处理最初选中的完整文字。例如，先点“总结”，再点“润色”，润色使用最初的中文选区。新动作使用自己配置的提示词和模型，结果在原位置更新，钉住状态也会保留。

结果窗口按“AI 动作”页的顺序排列其他已启用的自定义动作。若原文适合中文润色，已启用的“润色”也会按其在列表中的位置显示。当前动作会从候选中略去。超出窗口宽度的动作收在“更多”中。普通翻译或没有其他可用动作时，只显示结果。

“会议纪要”示例适用于会议转写、聊天记录和会议笔记，整理会议概况、讨论要点、已确认决策、待办及待确认问题。没有明确负责人或截止时间时标注“未明确”，不把讨论建议写成决策。“智能提取”按所选内容选择字段，多个同类对象使用表格，单个对象使用字段列表；保留名称、金额、单位和日期等原始值，歧义或冲突标注“待核实”，不访问链接或补造信息。

新建或编辑时可在同一窗口选择模型和编写提示词。内容较长时可滚动查看。四个示例位于新建窗口。

### 撤销上次优化

在编辑窗口中点击“优化提示词”，预览并“采用”后，会先保留采用前的完整提示词；不满意时点击“撤销上次优化”，恢复原内容并自动保存。翻译、润色及每个自定义动作各自保留最近一次记录，关闭设置或重启应用后仍可回退。只预览或取消不生成记录，普通编辑也不会覆盖该记录；没有记录时按钮置灰。

连续采用 A → B → C 后，撤销恢复到 B，只提供最近一次回退。撤销后清除这条记录，下次采用时重新生成。采用后又手动修改过提示词时，先提示当前内容将被优化前版本替换，再由你确认。回退不改变动作名称、模型、开关和排序；删除动作时一并清理对应记录。功能从本版“采用”开始记录，升级前已覆盖的提示词不会自动生成历史。

## 设置页面

打开设置默认进入「划词」。左侧可切换七个页面，系统权限入口固定在侧栏底部。

- **划词**控制选区旁的入口，可选择划词方式、试用示例、设置显示位置及排除应用。菜单栏的“在 Safari 中暂停划词与悬停翻译”等选项会同时暂停该应用内的划词和悬停翻译，剪贴板和截图翻译可独立使用。
- **翻译**：管理翻译服务开关、排序和悬停方式。功能总开关已移至“AI 动作”的翻译动作行右侧，可通过“管理 AI 动作”前往。关闭翻译会暂停外语划词、悬停、剪贴板和截图翻译；不影响润色。
- **结果窗口**可设置翻译、润色及自定义动作的显示位置和文字大小。设置页会用一张示例翻译卡片展示当前位置和字号。选“鼠标右下方”时，示意中会标出鼠标位置。点击“预览结果窗口”可在桌面查看同一条本地示例译文，体验拖动、钉住和复制。
- **AI 服务**用于配置账号、自定义 API 和全局模型。在“测试模型是否可用”一行点击“开始测试”，轻译会请当前全局模型翻译一句示例英文。关闭翻译也可以测试连接。
- **AI 动作**：页面顶部的“自定义动作栏设置”用于配置简洁模式的辅助键和触发方式，以及划词时的“动作栏显示上限”。结果窗口按可用宽度排列动作。翻译、润色和自定义动作统一采用紧凑列表，右侧开关可以分别启停动作。翻译和润色默认均开启。升级时，曾手动关闭润色的用户会保留该选择，未设置过润色开关的用户将采用新默认值。拖动任意动作标题即可调整显示顺序。点击名称、模型说明或标题空白处打开编辑弹窗，可编辑提示词和模型；内置动作可恢复默认，自定义动作可改名、删除，均可优化提示词。有效修改自动保存，关闭前提示尚未保存的无效内容。
- **通用**：剪贴板与截图快捷键、登录启动。
- **关于轻译**：版本、隐私和能力说明。

关闭从轻译打开的 macOS 权限设置后，轻译会返回之前的分类，保留未保存的输入。若你已切换应用、切换桌面、关闭或最小化轻译窗口，轻译会尊重当前窗口选择。

翻译服务列表支持整行拖动排序。浮窗会按新顺序展示已有结果。

API 模型目录直接位于密钥下方，无需切换子页面；模型可就地展开编辑，高级参数折叠显示。普通偏好即时生效；API 编辑点击保存才会提交，取消不保存。切换分类、返回或关闭窗口时若有未保存的修改，会询问继续编辑或放弃修改。

## 悬停翻译

在“翻译 → 悬停翻译”中分别设置“动作辅助键”和“触发方式”。辅助键可选 Option、Control、Shift、Command；触发方式支持“单次按键”（松开后执行，避免组合快捷键误触发）、“按住辅助键”（0.6 秒）和“长按鼠标左键”。选择鼠标方式时，辅助键选择暂不可用。旧版悬停手势保持原设置。

在简洁按钮模式中，若悬停翻译与自定义动作共用辅助键，有有效选区及可用自定义动作时优先打开动作栏。直接显示动作栏模式下，辅助键沿用悬停翻译设置。

## 截图翻译

从菜单栏选择“截图翻译”，或按已设置的截图快捷键，框选要翻译的区域。轻译先在本机识别文字，再将识别出的外语原文交给已开启的翻译服务。

等待译文时可以滚动原页面，无需钉住结果窗口。多家服务会各自显示译文，较慢的服务会在同一个窗口补齐。按 Esc 或点击未固定窗口外可结束本次翻译。OCR 超时后，点击「重试」会重新识别同一张图；要更换区域，再使用「截图翻译」重新框选。

## 思考模式

在“AI 服务”中可为支持的模型单独切换“思考模式”。未设置过的模型默认开启，已保存的选择会保留。翻译、润色、自定义动作、提示词优化和模型连接测试都按实际选用模型的设置发送请求。

| 模型与协议 | 开启 | 关闭 |
| --- | --- | --- |
| 支持控制思考的 OpenAI 模型，包括 ChatGPT 订阅 | 请求 `medium` | 请求 `none` |
| 支持控制思考的 DeepSeek 模型 | Chat Completions 请求 `enabled`，Responses 请求 `high` | 相应协议请求 `disabled` 或 `none` |
| 支持控制思考的 Claude 模型 | 支持自适应思考时请求 `adaptive`，使用显式预算的型号请求 1,024 个思考 token | 请求 `disabled` |
| 未识别出思考控制方式的模型 | 由服务决定 | 由服务决定 |

开关下方显示这个模型上次成功回复时是否使用了思考模式。模型连接测试也会更新这条记录。若服务没有说明是否使用思考，轻译会标明这一点，并在已请求开启或关闭时显示当时的选择。若服务拒绝参数，错误提示会显示模型 ID、请求的模式和对应参数。若请求完成却没有正文，轻译会按原文、提示词、模型和思考设置自动再试一次。再次返回空正文时，结果窗口会提示错误。

## AI 动作与提示词编辑

在“AI 动作”页，每个动作行直接显示“全局默认／独立选择”、服务及模型名称。未配置或模型不可用时明确提示；长名称悬停查看全名。点击名称、模型说明或标题空白处打开编辑弹窗，右侧功能开关独立操作。列表不展开编辑区；在弹窗中修改提示词及模型，点击“完成”返回。内置动作名称固定，自定义动作名称可编辑，名称下方提示“动作名称会显示在浮窗按钮上，建议不超过 4 个字。”。

每个功能默认“跟随全局”模型，也可选择独立模型。模型偏好保存在本机；浮窗临时模型仍仅影响本次任务，“恢复默认模型”回到该窗口开始时的功能模型。

有效的提示词修改即时自动保存，保留原输入和换行，没有保存按钮。首次打开时，默认内容显示“内置默认”，自定义内容显示“已修改 · 自动保存”。每次有效输入并保存后，状态切换为绿色勾选及“已保存 HH:mm:ss”，更新本次保存时间并播放确认动画；同一秒内继续输入也会重新触发确认。空白输入或保存失败显示“尚未保存”及原因，不会误报保存成功，仍使用上次有效内容；另一个编辑区不受影响。恢复默认只作用于当前提示词，立即保存。

优化使用 **当前动作选择的模型**；仅当动作选择“跟随全局”时使用全局模型。预览会标明实际使用的模型。只在点击后发送当前提示词，先展示当前与优化后的完整内容。当前内容只读，优化结果可以继续编辑。点击“采用”后，新提示词会替换原内容并自动保存，保留最终编辑内容中的换行。空白结果不能采用，取消或失败保留原内容。动作配置的模型不可用时提示重新选择并禁用优化，不会自动改用其他模型。独立模型可在未配置全局模型时直接用于优化。提示词优化同样限制 12,000 字；不自动运行。

新任务使用最新已保存提示词；当前窗口的重试、临时切换模型和自动重试始终使用该任务开始时的提示词快照。提示词仅保存在本机，随请求发给所选 AI；有道、谷歌不使用提示词。API 配置仍需明确保存，未保存离开时保留继续编辑／放弃修改保护。

## ChatGPT 账号连接

浏览器收到授权回调后，会显示“授权信息已接收”。请返回轻译查看最终登录结果，随后可以关闭浏览器页面；该提示不代表身份验证已完成。回调页面支持浅色、深色和窄屏显示，全部资源来自本机。

同一邮箱可以有多个独立授权连接，例如个人和工作区连接。轻译分别保留每个连接的凭据和模型选择，同邮箱时显示连接编号；切换或重新授权不会合并其他连接。删除和退出只影响选中的连接。

升级会取消旧版按邮箱生成的待删除队列。此前已经被旧版删除的凭据无法自动恢复，需要重新授权；尚未删除的凭据和模型偏好会保留。

## 自定义 API 配置

1. 设置→AI 服务→**添加 API**，填写显示名称、API 基础地址、协议和密钥。无需先登录 ChatGPT。
2. 输入带协议的基础地址，例如 `https://gateway.example`。省略路径时会自动补上 `/v1`，已有的 `/proxy/v1` 等网关路径会保留。不要填写完整的 `/chat/completions`、`/responses` 或 `/messages` 接口。支持 HTTPS，本机 localhost 可使用 HTTP。
3. 点击 **获取模型列表**，勾选需要的模型并导入；也可点击 **手动添加模型**，填写模型 ID 和显示名称。获取失败不影响手动添加。获取动作会向填写的 API 地址发送密钥，但不发送待翻译文字。
4. 可选最大输出 token 数：留空时 OpenAI 不额外设置，Anthropic 使用 8,192；被模型拒绝时可修改此值。Chat Completions 的限制参数采用 `max_completion_tokens`，Responses 使用 `max_output_tokens`，Anthropic 使用 `max_tokens`。
5. **支持图片输入**只记录你声明的模型能力，默认关闭，不表示已验证。截图翻译先进行本机 OCR，再发送文字；不使用模型图片输入能力。
6. 点击保存，随后在“全局 AI 模型”下选中该提供商，再选择默认模型。可以先保存提供商，之后再编辑并添加模型。
7. 点击 **开始测试**。轻译会请默认模型翻译一句示例英文，服务商可能收取 API 费用。成功后，提示中会显示已测试的模型名称。

每个提供商保留自己的模型选择。编辑配置时密钥框留空会保留原密钥；填入新值则更新。取消编辑不保存，获取或导入模型后仍需点击保存。重复获取不会覆盖已有模型的显示名称、图片能力或输出上限。

OpenAI 协议使用 Bearer API Key；Anthropic 使用 `x-api-key` 和兼容 API 版本 `2023-06-01`，模型列表支持分页。第三方网关需兼容所选协议；Azure 等需要额外特定认证或查询参数的接口不在本版范围内。

删除提供商会删除对应钥匙串密钥；删除正在使用的提供商或模型后，需要重新选择。请求失败时不会自动切换到其他服务，也不会自动改用 ChatGPT 额度。

## 当前译文临时切换模型

AI 结果卡片标题区的模型按钮采用浅底、细描边和圆角，名称旁的下拉箭头始终可见；点击按钮任意位置均可选择其他模型，悬停和按下时会有底色反馈。菜单按已保存的提供商分组，并包含当前 ChatGPT 账号的模型；长名称截断显示，悬停可查看完整模型名、服务商及翻译状态。

- 选择其他模型后，立即用所选服务重新翻译当前完整原文，保持窗口位置；选择当前模型不会重复请求。
- 临时模型旁标注“本次”。重试沿用这个模型，“恢复默认模型”使用当前窗口打开时的默认模型。
- 关闭浮窗，或重新划词、触发剪贴板/验证翻译时，临时选择清除，新任务使用设置页的默认服务和模型。
- ChatGPT 模型尚未加载时，点击“加载 ChatGPT 模型…”，加载完成后重新打开菜单选择；该操作不调整默认模型或切换 ChatGPT 账号。
- 翻译进行中或失败时也可切换；预览模式禁用模型选择。失败不会自动换用其他服务。钥匙串读取在后台进行；系统授权未完成时等待用户处理，完成授权后继续本次翻译，取消翻译会停止等待。主动切换其他应用时不会抢回焦点。
- 菜单打开时，Esc 只取消菜单；菜单关闭后的 Esc 才关闭浮窗。选择会把当前原文发送给所选服务，并使用对应额度。

临时选择仅在内存中保存，不写入提供商、模型偏好或钥匙串。

## 数据与服务边界

划词检测及 Vision OCR 在 Mac 本机完成。翻译任务会将原文从本机直接发送给你开启的有道、谷歌和已配置的 AI 服务。截图翻译发送 OCR 识别出的文字。中文润色与自定义动作仅向该动作所选的 AI 发送原文及提示词；优化提示词会将待优化的提示词发给该动作的模型。

两家内置服务默认开启，各自单次最多接收 5,000 字。轻译使用它们的网页服务，这些接口可能随服务方调整、限流或网络变化而失效。如果你只希望特定提供商接收原文，可在「设置 → 翻译」关闭其余服务。AI 文本任务单次最多 12,000 字，实际可用长度和费用还取决于模型与服务商。接口实现和资源说明见[第三方服务与许可证](../THIRD_PARTY_NOTICES.md)。

## 常见问题

**划词后没有按钮**

先在“设置 → 划词”的试用区比较中英文选区。首次安装时翻译和润色均开启，外语示例应显示翻译入口，中文示例应显示润色入口。在“AI 动作”中可查看相应开关。要试用自定义动作，请先创建一个动作，再选一句正文。如果试用正常，请确认轻译有辅助功能权限，且当前应用允许读取选区、未被排除。

**系统开关已开，轻译仍提示需要权限**

若刚切换签名身份，在系统辅助功能列表移除旧条目，再重新添加当前安装路径的 `轻译.app` 并开启。轻译每两秒刷新一次状态。后续更新应沿用原证书和安装位置。

**快捷键无法保存或被占用**

只按修饰键不会保存。系统保留、已占用或无法注册的组合会提示失败，并保留原组合；可重新录制其他组合。

**账号、模型或翻译报错**

检查网络及系统代理。ChatGPT 可刷新模型或重新授权；自定义 API 请检查基础地址、协议、密钥和模型 ID。获取模型失败可手动添加。额度不足或限流时查看对应服务商用量并稍后重试。模型出现在列表中仍需成功请求一次才能确认当前访问权限。

## 源码构建与测试

源码编译与测试需要 Apple Silicon Mac、Apple Command Line Tools 及 Swift 编译器。程序链接 macOS 系统框架，运行时仍需联网使用你选择的翻译服务。

在源码根目录运行自动化测试。此步骤可在没有维护者签名私钥的开发机执行。AppKit、Vision 和快捷键相关实测需要已登录的 macOS 图形会话。

```bash
bash test.sh
```

发行构建脚本绑定原 `Qingyi` 证书，需在持有对应私钥的维护者 Mac 上执行；仓库中的公开证书不能替代私钥。使用其他签名身份构建将产生不同的应用身份。

```bash
bash Tools/setup-signing.sh  # 检查固定签名身份
bash build.sh
```

默认构建只生成 ZIP 安装包，避免产生可被搜索索引到的重复 App。签名身份缺失时会停止，不会自动重新生成证书或回退到临时签名。

可选验证：

```bash
bash test.sh --loopback  # 本机 OAuth 回调、页面响应及取消流程
bash test.sh --hotkeys   # 真实 Carbon 快捷键注册与冲突
bash Tools/test-signing.sh ../轻译-macOS.zip
bash test.sh --ui-snapshots ../work/ui-snapshots  # 仅用测试数据渲染界面
bash test.sh --callback-page-previews ../work/callback-previews  # 使用实际模板导出三种回调页面
```

功能测试使用固定或临时测试数据，不登录 ChatGPT 或调用真实模型；自定义 API 网络路径使用 URLProtocol 模拟分片响应。已签名应用可通过 `--api-credential-check` 验证独立钥匙串的随机诊断记录读写删除，不读取现有密钥。签名升级检查使用维护者的签名私钥，在临时目录生成下一构建，不修改已安装应用。

要验证自己的全局默认模型，可在「设置 → AI 服务」点击「开始测试」。维护者也可从已签名 App 的可执行文件运行 `--default-translation-check --actions`，用公开样例依次检验翻译、润色、总结、提取和提示词优化。这些请求使用所选模型的实际额度。添加 `--screenshot-input 图片路径` 可同时验证本机 OCR 到中文翻译的流程。诊断图片应仅显示英文 `The green bag contains 36 apples.`，识别文本与样句吻合后才会发送给模型。

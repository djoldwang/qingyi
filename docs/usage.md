# 轻译使用手册

## 设置页面

左侧按使用顺序排列为 **翻译触发、译文窗口、翻译服务、通用、关于轻译**。打开设置默认进入翻译触发；右侧直接展示分组内容，不重复显示页面大标题。

- **翻译触发**：划词与悬停分别启用，设置按钮位置及悬停手势，并管理共用的排除应用列表。点击“添加应用…”可用系统选择框多选 .app；每行“移除”会恢复该应用的自动划词，菜单栏的排除操作与这里同步。
- **译文窗口**：默认出现位置、位置示意与无需模型请求的浮窗预览。菜单栏下拉菜单中已移除预览入口。
- **翻译服务**：开启内置服务、拖动调整结果顺序，并选择默认 AI 服务和模型；“管理账号”打开 ChatGPT 账号管理，“编辑配置”打开对应 API。
- **通用**：统一录制剪贴板与截图翻译快捷键，并设置登录 Mac 时启动。系统权限统一位于左下卡片。
- **关于轻译**：版本、隐私与当前能力说明。

系统权限卡片常驻侧栏底部，分别显示辅助功能与屏幕录制的授权状态，点击对应行进入各自的 macOS 系统设置页面。返回采用单次无动画前置，保持原窗口与内容。 关闭本次打开的系统设置后，原轻译设置窗口会回到前台，保留分类和未保存输入；如果你已主动切换应用、切换桌面，或关闭/最小化轻译设置窗口，则取消自动返回。

API 模型目录直接位于密钥下方，无需切换子页面；模型可就地展开编辑，高级参数折叠显示。普通偏好即时生效；API 编辑点击保存才会提交，取消不保存。切换分类、返回或关闭窗口时若有未保存的修改，会询问继续编辑或放弃修改。

## ChatGPT 账号连接

同一邮箱可以有多个独立授权连接，例如个人和工作区连接。轻译分别保留每个连接的凭据和模型选择，同邮箱时显示连接编号；切换或重新授权不会合并其他连接。删除和退出只影响选中的连接。

升级会取消旧版按邮箱生成的待删除队列。此前已经被旧版删除的凭据无法自动恢复，需要重新授权；尚未删除的凭据和模型偏好会保留。

## 自定义 API 配置

1. 设置→翻译服务→**添加 API**，填写显示名称、API 基础地址、协议和密钥。无需先登录 ChatGPT。
2. 基础地址示例：`https://gateway.example/v1`。仅填写域名时自动补 `/v1`；`/proxy/v1` 等网关前缀会保留。不要填写完整的 `/chat/completions`、`/responses` 或 `/messages` 接口。支持 HTTPS，本机 localhost 可使用 HTTP。
3. 点击 **获取可用模型**，勾选需要的模型并导入；也可点击 **手动添加模型**，填写模型 ID 和显示名称。获取失败不影响手动添加。获取动作会向填写的 API 地址发送密钥，但不发送待翻译文字。
4. 可选最大输出 token 数：留空时 OpenAI 不额外设置，Anthropic 使用 8,192；被模型拒绝时可修改此值。Chat Completions 的限制参数采用 `max_completion_tokens`，Responses 使用 `max_output_tokens`，Anthropic 使用 `max_tokens`。
5. **支持图片输入**只记录你声明的模型能力，默认关闭，不表示已验证。截图翻译先进行本机 OCR，再发送文字；不使用模型图片输入能力。
6. 点击保存，随后在“AI 翻译”下选中该提供商，再选择翻译模型。可以先保存提供商，之后再编辑并添加模型。
7. 点击 **验证一次翻译**。验证会发送固定英文样例，使用服务商 API 额度；出现在模型列表中不代表已验证访问权限。

每个提供商保留自己的模型选择。编辑配置时密钥框留空会保留原密钥；填入新值则更新。取消编辑不保存，获取或导入模型后仍需点击保存。重复获取不会覆盖已有模型的显示名称、图片能力或输出上限。

OpenAI 协议使用 Bearer API Key；Anthropic 使用 `x-api-key` 和兼容 API 版本 `2023-06-01`，模型列表支持分页。第三方网关需兼容所选协议；Azure 等需要额外特定认证或查询参数的接口不在本版范围内。

删除提供商会删除对应钥匙串密钥；删除正在使用的提供商或模型后，需要重新选择。请求失败时不会自动切换到其他服务，也不会自动改用 ChatGPT 额度。

## 当前译文临时切换模型

AI 结果卡片标题区的模型按钮采用浅底、细描边和圆角，名称旁的下拉箭头始终可见；点击按钮任意位置均可选择其他模型，悬停和按下时会有底色反馈。菜单按已保存的提供商分组，并包含当前 ChatGPT 账号的模型；长名称截断显示，悬停可查看完整模型名、服务商及翻译状态。

- 选择其他模型后，立即用所选服务重新翻译当前完整原文，保持窗口位置；选择当前模型不会重复请求。
- 临时模型旁标注“本次”。重试沿用这个模型，“恢复默认模型”使用当前窗口打开时的默认模型。
- 关闭浮窗，或重新划词、触发剪贴板/验证翻译时，临时选择清除，新任务使用设置页的默认服务和模型。
- ChatGPT 模型尚未加载时，点击“加载 ChatGPT 模型…”，加载完成后重新打开菜单选择；该操作不调整默认模型或切换 ChatGPT 账号。
- 翻译进行中或失败时也可切换；预览模式禁用模型选择。失败不会自动换用其他服务。钥匙串读取在后台进行；系统授权未完成时等待用户处理，完成授权后继续本次翻译，取消翻译会停止等待。主动切换其他应用时不会抢回焦点。
- 菜单打开时，Esc 只取消菜单；菜单关闭后的 Esc 才关闭浮窗。选择会把当前原文发送给所选服务，并使用对应额度。

临时选择仅在内存中保存，不写入提供商、模型偏好或钥匙串。多模型并排对比不在本次范围内。

## 常见问题

**划词后没有按钮**

确认辅助功能权限已开启，未暂停或排除当前软件，并选择外语测试。部分软件不提供选区，请复制后使用快捷键。

**系统开关已开，轻译仍提示需要权限**

若刚切换签名身份，在系统辅助功能列表移除旧条目，再重新添加当前安装路径的 `轻译.app` 并开启。轻译每两秒刷新一次状态。后续更新应沿用原证书和安装位置。

**快捷键无法保存或被占用**

只按修饰键不会保存。系统保留、已占用或无法注册的组合会提示失败，并保留原组合；可重新录制其他组合。

**账号、模型或翻译报错**

检查网络及系统代理。ChatGPT 可刷新模型或重新授权；自定义 API 请检查基础地址、协议、密钥和模型 ID。获取模型失败可手动添加。额度不足或限流时查看对应服务商用量并稍后重试。模型出现在列表中仍需成功请求一次才能确认当前访问权限。

## 源码构建与测试

运行时无需第三方依赖。构建需要 Apple Silicon Mac、Apple Command Line Tools 和 Swift 编译器。

发行构建脚本绑定原 `Qingyi` 证书，需在持有对应私钥的维护者 Mac 上执行；仓库中的公开证书不能替代私钥。使用其他签名身份构建将产生不同的应用身份。

```bash
bash Tools/setup-signing.sh  # 只检查固定签名是否可用
bash test.sh
bash build.sh
```

默认构建只生成 ZIP 安装包，避免产生可被搜索索引到的重复 App。签名身份缺失时会停止，不会自动重新生成证书或回退到临时签名。

可选验证：

```bash
bash test.sh --loopback  # 本机 OAuth 回调及取消流程
bash test.sh --hotkeys   # 真实 Carbon 快捷键注册与冲突
bash Tools/test-signing.sh ../轻译-macOS.zip
bash test.sh --ui-snapshots ../work/ui-snapshots  # 仅用测试数据渲染界面
```

功能测试使用固定或临时测试数据，不登录 ChatGPT 或调用真实模型；自定义 API 网络路径使用 URLProtocol 模拟分片响应。已签名应用可通过 `--api-credential-check` 验证独立钥匙串的随机诊断记录读写删除，不读取现有密钥。签名升级检查使用维护者的签名私钥，在临时目录生成下一构建，不修改已安装应用。
